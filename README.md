# 🎬 Netflix Clone

A responsive Netflix-inspired website built using **HTML and CSS**. The project focuses on recreating the visual design, layout, and overall user interface of a modern streaming platform.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Responsive design
* Netflix-inspired UI
* Hero section with background image
* Navigation bar
* Movie/show sections
* Clean and modern layout
* CSS-based styling and positioning

## 🎯 Purpose

This project was created to practice **HTML and CSS**, with a focus on responsive layouts, positioning, styling, and recreating a real-world website interface.
